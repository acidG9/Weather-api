# 🌤️ Breezer – Real-Time Weather App (React)

**Breezer** is a modern, responsive weather application built with **React**. It fetches real-time weather data for any city worldwide using the [OpenWeatherMap API](https://openweathermap.org/api). The app provides current conditions, hourly forecasts, and more, all presented in a clean and intuitive user interface.

> 🚀 **Live Demo**: [breez3r.vercel.app](https://breez3r.vercel.app/)

---

## ✨ Features

- 🔍 Search for weather by city name
- 🌡️ Display of temperature, humidity, wind speed, and more
- 🕒 Hourly forecast for the current day
- 📱 Fully responsive design for mobile and desktop

---

## 🛠 Tech Stack

- **React** – Frontend library
- **CSS3** – Styling and layout
- **OpenWeatherMap API** – Weather data source
- **Vercel** – Deployment platform
